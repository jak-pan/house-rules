- FIX-NOW: a real, reachable defect with real impact (security, data loss, correctness, a contradiction of the spec or an operator decision), or waste whose fix is a deletion of a few lines. These go into the single fix round.
- ISSUE: real, but out of this PR's scope, pre-existing, or its fix would add a new mechanism or noticeably grow the PR. It becomes a separate tracked issue, not part of this PR.
- Settled decisions win: before calling a contract "unresolved", check the repository's recorded operator decisions and the design. If a recorded decision already says what must happen and this PR's scope covers it, the finding is FIX-NOW, not ISSUE.
- Deleting or weakening requirement text (a spec, design, rule or prompt sentence) is never a smallest fix and never accepted without a recorded decision ID; reviewer verdicts such as 'overbuilt' or 'waste' are proposals, not decisions.
- NITPICK: theoretical or very unlikely triggers with negligible impact, style, wording, preferences, or "could be stronger" without a written requirement. Rejected. A trigger that needs several independent rare conditions at once (for example a repository changing visibility mid-round AND a failing API read AND a non-default mode) is NITPICK unless it is a real security defect (someone acts without permission or secret content leaks) or loses data; say which conditions make it rare.
- FALSE: not real, not reachable, or contradicted by the design or an operator decision. Rejected.
Complexity rule: for every FIX-NOW, give the SMALLEST fix, preferring deletion or narrowing. If the only fix you can see adds a new mechanism, state, config or abstraction, classify it ISSUE unless it is security, data loss, or a cost defect. Never accept a fix that makes the PR bigger than the problem justifies; a fix whose lines are reasoned for and necessary is fine. Cost defect (a blocking kind): work per operation that grows with stored data where an index or native filter should bound it, extra native or storage calls per operation beyond the spec or a recorded budget, or a measured regression in a benchmark or count assertion. A cost defect with a concrete operation and its count or measurement is FIX-NOW even if the fix adds an index, a native filter or a test.
